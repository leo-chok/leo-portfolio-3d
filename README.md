## ✨ Concept

Plutôt qu'un portfolio classique, j'ai créé une **expérience spatiale interactive** où les visiteurs deviennent des explorateurs. Naviguez dans un système solaire 3D, orbitez autour des planètes, et découvrez mes compétences, projets et formations de manière immersive.

> 🎯 **L'objectif ?** Que chaque visiteur ressente la passion que je mets dans mes projets, dès la première interaction.

---

## 🌌 Fonctionnalités

### 🪐 Expérience 3D Interactive
- **5 planètes thématiques** à explorer (Compétences, Formations, Projets, Contact...)
- **Système d'analyse** : cliquez sur une planète pour révéler son contenu
- **Caméra orbitale fluide** avec zoom et rotation
- **Mothership NPC** vagabonde dans l'espace
- **Effets visuels** : nébuleuses, Voie Lactée, particules stellaires

### 🖥️ Interface HUD Sci-Fi
- **Fenêtres holographiques** draggables et redimensionnables
- **Barre de progression** de découverte
- **Animations cyberpunk** (glitch, scan, typing effect)
- **Support mobile** avec HUD adaptatif

### 📄 Version CV Scrollable
- **Alternative accessible** pour les recruteurs pressés
- **Animations au scroll** avec Intersection Observer
- **Design cohérent** avec l'univers spatial

### 🎮 Easter Egg Secret
> *« Les explorateurs les plus curieux seront récompensés... »*
> 
> Analysez les 5 planètes du système pour débloquer une **surprise** 👀

## 🛠️ Stack Technique

| Catégorie | Technologies |
|-----------|-------------|
| **Frontend** | React 19, Vite |
| **3D Engine** | Three.js, React Three Fiber, Drei |
| **State** | Zustand |
| **Animations** | GSAP, CSS Animations |
| **Routing** | React Router v7 |
| **Styling** | CSS Vanilla (BEM) |
| **Deployment** | Vercel |


## 📁 Structure du projet

```
src/
├── pages/              # Routes (Welcome, Resume, Experience)
├── components/
│   ├── 3d/             # Composants Three.js (planètes, vaisseaux, scène)
│   └── hud/            # Interface utilisateur (fenêtres, vues, taskbar)
├── stores/             # State management (Zustand)
├── data/               # Contenu statique (skills, projets, formations)
└── hooks/              # Hooks custom (useInView, useIsMobile)
```
